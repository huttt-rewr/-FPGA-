## 使用方法

菜单默认关闭，不再在照片或视频上常显四行英文状态面板。原有字幕、中文标语、音频波形、媒体播放和蛇游戏保留各自控制。

1. 长按KEY3约1秒，达到门限即打开菜单；打开时选中“播放”，处于列表状态。松开不会额外执行一次确认。
2. 列表状态下，KEY1向上、KEY2向下，八项循环选择。选中行的文字、数值及操作提示按2倍显示，黄色高亮；其他行是灰色16×16字。
3. 在“播放、伽马、静音、诊断”上短按KEY3，直接切换，不进入数值编辑。
4. 在“亮度、对比度、音量”上短按KEY3，进入编辑；KEY1减小、KEY2增大，选中行保持不动，右侧提示变为“返回”。再短按KEY3回到列表。
5. 在列表或编辑状态长按KEY3约1秒，关闭菜单。选中“退出”短按KEY3也能关闭。

长按不会额外触发短按，按住KEY1/KEY2不会自动连发。两键同时按下不移动、不调值。菜单关闭后，原有KEY3短按切换播放/亮度/对比度快捷模式仍保留。

| 菜单项 | 显示/操作 | 范围或含义 |
|---|---|---|
| 播放 | 播放/暂停 | KEY3切换自动播放状态，仍由原播放器消费请求 |
| 亮度 | 带符号两位数 | -64～+63，每次8；端点饱和，不回绕 |
| 对比度 | 数字 | 原寄存器2～8，对应0.50～2.00倍，步进0.25倍 |
| 伽马 | 开/关 | 切换原有暗部提亮LUT |
| 音量 | 两位数字 | 0～16，和键盘/红外共用唯一音量寄存器 |
| 静音 | 开/关 | 切换唯一静音寄存器，不另存菜单副本 |
| 诊断 | 开/关 | 切换原有板载数码管诊断显示使能，不恢复旧英文状态面板 |
| 退出 | 确认 | 短按退出；也可在任何项长按KEY3退出 |

参数复位后恢复默认值，不做断电保存。新菜单不改变WAV或AVF支持的格式；实际640输出模式仍为纯视频，声音沿用实际800×600模式。

键盘O键和对应红外OSD键继续控制原音频波形层。中文菜单独立由KEY3控制，O键不会阻止打开菜单；SW原有像素效果、字幕、滚动和转场控制保持原样。

## 画面和显示器适配

菜单在逻辑640×480视口内绘制。实际输出800×600时，复用已有viewport_coordinates按floor(raw×4/5)产生逻辑坐标，菜单随屏幕等比适配。选中行在逻辑视口中严格由16×16点阵复制为32×32，每个原像素对应2×2输出像素。

菜单标题是“菜单”，底部提示为“上下 确认 返回 长按退出”。菜单所有文字和状态均来自中文字模；数值、正负号使用同一16×16字库中的ASCII符号。以下是实际RTL仿真输出，不是手工效果图：

![彩色渐变亮度编辑状态仿真](../reports/menu_gradient_20261023/menu_edit.png)

渐变在逻辑面板y=16～447内每16行变化一级，共27级。新增y1寄存器与原视频流水线同步，不增加显示延迟；800×600输出继续使用原有逻辑坐标适配。

## 字库再生成

在工程根目录执行：

```powershell
python scripts/gen_zh_font.py --preview reports/chinese_menu_20261023/font_preview.png
python scripts/test_zh_font.py
```

默认字体是C:\Windows\Fonts\simhei.ttf，可用--font明确指定。像素格式为每字16行、每行16bit，bit15是最左像素。0～31保持原始字形和预留空白，32～62是31个中文字符，63～72是数字，73是空格，74/75/76为+/-/:。

脚本读取现有mem的原512word并与旧RTL初始化交叉核对，再追加新字，不会重新绘制原标语。字库内容全部内嵌在zh_font_rom.v；仿真里的参考数据文件不参与硬件运行时加载。

默认BANK=0保留完整77字、1232word及原始索引。正式标语实例用BANK=1，只实例化旧32字；菜单用BANK=2，只实例化新增45字，外部索引仍为32～76。生成脚本同时生成三个bank的常量，字体测试逐word核对裁剪bank与完整表一致，避免两个使用者都占一份完整字库。所有bank均同步读取一拍，不增加视频流水延迟。
