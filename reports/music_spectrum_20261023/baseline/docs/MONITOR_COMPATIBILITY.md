# 当前双模式显示参数与兼容排查

这是现有640×480/800×600设计的参数说明，本轮不增加输出分辨率或改官方PLL。先连接HDMI_B并打开显示器，再复位；启动EDID明确支持800×600时选择该档，否则回退640×480。

| 参数 | VGA | SVGA |
|---|---:|---:|
| 像素/串行时钟MHz | 25 / 125 | 40 / 200 |
| HACTIVE / HTOTAL | 640 / 800 | 800 / 1056 |
| HSA / HFP / HBP | 96 / 16 / 48 | 128 / 40 / 88 |
| VACTIVE / VTOTAL | 480 / 525 | 600 / 628 |
| VSA / VFP / VBP | 2 / 10 / 33 | 4 / 1 / 23 |
| 行频kHz | 31.250 | 37.879 |
| 帧频Hz | 59.524 | 60.317 |
| 内部HS/VS | 低有效 / 低有效 | 低有效 / 低有效 |

表中极性是`adaptive_raster`的内部同步；官方HDMI核自行生成输出链路时序，不能把内部HS/VS电平当作核的可配置链路极性。低有效VS下降沿也是当前换帧/参数锁存/看门狗心跳的约定，直接翻转会改变下游行为。

640×480并非标准25.175MHz版本；1920×1080面板可以接收较低模式，但实际接受能力以EDID和上板为准。显示器菜单建议保持比例，不是拉伸全屏。伽马只是可选暗部提亮，不代表校准或HDR。

不识别时先核对输入源、B口、复位与EDID、位流版本、供电和线材；再检查输出是否实际选择期望模式以及PHY警告。若将来调整前/后沿，应同时更新`src/top.v`两HDMI实例、`adaptive_raster.v`内部总时序/有效区和相应测试，保证总和一致；某些官方核接口没有独立极性参数，不能编造一个参数写进去。修改后必须重新完整回归、实现和实板测试。本轮保留已通过参数，没有为了某台未知显示器盲目微调。

PLL改为25.175MHz属于单独的时钟/IP重生成工作，本轮禁止改官方IP所以暂缓；HDMI音频未来若启用，该频率的CTS应为25175（N=6144，48kHz），当前实际25MHz应为25000。不能只改CTS而不改真实像素和采样节拍。
