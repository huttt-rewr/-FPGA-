# PS/2 键盘操作与实施状态

更新：2026-10-16。本文记录正在分阶段验证的新源码；旧 bit 不包含键盘功能。是否完成整机时序与下载验收以 [构建状态](BUILD_STATUS.md) 及本轮报告为准。

## 接线与启动

HDMI 仍连接 **HDMI_B**，TF 卡仍按 [FAT32 教程](FAT32_USAGE_20261015.md) 准备。正式 SD 接口目前仍是 SPI、25MHz，不是 50MHz。

使用板上匹配的 PS/2 键盘接口。官方例程 `J:/DEMO/14_ps2_piano/A1.adc` 与 `J:/DEMO/24_VGA_shiyan9_B/VGA.adc` 一致指定：PS/2 CLK 对应 FPGA M16，DATA 对应 K16，LVCMOS33、上拉。新顶层命名为 `ps2_clk`、`ps2_data`，约束已同步。不要把 USB 键盘的 D+/D−直接连接这两个信号；普通 USB 键盘加被动转接头也未必支持 PS/2。板口供电及电平转换要按实际原理图核对，例程管脚表本身不能证明任意外接键盘的电气兼容性。

先断电连接键盘、显示器和卡，再上电/复位。当前接收器使用 PS/2 Set 2 扫描码，只接收，不发送键盘配置命令，不控制 Caps Lock 等指示灯。输入在 100MHz 系统域同步、滤波后解码，键盘时钟不作为 FPGA 内部逻辑时钟。

## 阶段一已经接入的键

| 键 | 操作 | 说明 |
|---|---|---|
| → / ← | 下一张 / 上一张 | 首尾循环；加载期间最多保留一个请求，长按不会连续跳图 |
| 空格 | 自动播放开/关 | 与板上 PLAY 控制共用状态；没有新建另一套自动播放状态 |
| ↑ / ↓ | 音量加一 / 减一 | 0～31，初始 8；允许键盘长按连发，到边界停止 |
| M | 静音开/关 | 与 KEY3 菜单的 AUDIO MUTE 使用同一个寄存器 |
| O | 隐藏/显示状态 OSD | 复位显示，整帧边界更新；字幕与转场仍由 SW 控制 |

**新顶层按本轮要求默认不静音**，音量 8。历史版默认静音的说明只适用于旧版本。插有合规 WAV 时可能自动开始读取音频；初次试用可先按 M 静音。是否实体显示器出声仍需上板确认。格式约束保持 48kHz、16bit、单声道 PCM WAV。

KEY1/2/3 与四路 SW 的功能继续保留，见 [KEY/SW 教程](KEY_SW_OPERATION.md)。键盘上下始终调整音量，板载按键仍按当前 PLAY/BRIG/CONT 或菜单上下文工作。O 关闭的是状态 OSD；SW 控制的独立字幕层不会随之关闭。复位后恢复默认状态。

除音量方向外，每次物理按下只触发一次；必须松开再按才能再次切换。数字小键盘的非扩展扫描码不会误当方向键。坏帧/超时会清除前缀和按住记录，避免一次通信损坏后一直卡键。

## 数字选文件与R/F状态

| 键 | 预定功能 | 当前现状 |
|---|---|---|
| 0～9 | 按从零开始的序号选图片 | 阶段二已接入，0是第一张，9是第十张 |
| A，然后数字 | 按从零开始的序号选 WAV | 阶段二已接入；A后2秒内数字选前十WAV，Esc取消 |
| R | VGA / SVGA / 小素材缩放档 | 阶段三已接入：先复位、切25/40MHz像素及配对串行时钟、稳定后重挂载重载；SVGA受EDID限制 |
| F | 循环 1/2/5/10/15/30 次每秒的换图请求档 | 只锁存 `fps_mode`，仍使用旧自动播放间隔 |

F 是请求换图频率，不是 HDMI 刷新率。实际速度还取决于 SD、源图尺寸、缩放计算、双缓冲提交和转场时间。320×240 指低分辨率素材放大到 VGA，不代表新增 320×240 HDMI 输出。后续不能把选择请求直接组合进时钟选择器，必须安全停机、复位、切换并重新加载。

当前正式FAT32为BMP/WAV合计64份索引，左右遍历全部图片，数字直达前十图/A+数字直达前十WAV；不支持两位数字输入。原生四位 SD 是独立候选；官方手册已确认 DAT1=B15、DAT2=A11 及10kΩ上拉，待正式集成与实板验证，见 [四位 SD 说明](SD_NATIVE_4BIT_20261016.md)。

## ModelSim 验证

在工程根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_keyboard_tests.ps1
python scripts/static_check.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_tests.ps1
python scripts/run_build.py
```

`sim/tb_ps2_keyboard.v` 从 PS/2 线级发送11位帧，检查同步/滤波、奇校验、E0/F0、Pause/BAT、损坏与超时恢复。`sim/tb_ps2_controls.v` 检查键位、数字等待、重复策略，以及键盘与真实 `picture_controls` 共用音量/静音。专项使用独立 `keyboard_work` 库；全量回归新增这两项。仿真通过只能证明这些激励下的逻辑行为，不能代替键盘电气和板级出声验收。

## 阶段三的R注意事项

R顺序默认1(VGA)→2(SVGA请求)→0(小素材VGA)→1。2不受支持时回退VGA；0和1都输出640×480。0档不会自动把大图变成320×240文件；要节省读卡带宽，需要事先转换小素材。

切档会暂黑并重载所选图片，键盘与音量/静音设置保留；自动轮播暂停，加载完成后再按空格。F仍待下一阶段。新源码的75项回归和STA见构建状态；本阶段没有新bit或实板验收。
