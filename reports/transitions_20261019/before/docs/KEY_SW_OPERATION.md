## 新增：KEY3长按菜单怎样用

普通模式短按KEY3并松开，仍循环PLAY→BRIG→CONT；短按在松开消抖后生效。长按KEY3约1.1秒再松开打开菜单，再长按关闭。长按不会同时切换普通MODE或确认条目。KEY1/2原功能只在菜单关闭时使用；菜单内KEY1向上、KEY2向下，KEY3短按确认。条目首尾循环，长按KEY1/2不连发。

| 菜单条目 | KEY3短按后的结果 | 默认值 |
|---|---|---|
| PLAY / PAUSE | 开关原有自动播放；看PLAY:ON/OFF确认 | OFF |
| GAMMA | 开关图片暗部提亮，便于比较暗部细节 | OFF |
| DIAG | 开关六位数码管诊断，OFF仍显示原SD状态 | OFF |
| DIAG PAGE | 0→1→2→3→0循环诊断页；需DIAG为ON才可见 | 0 |
| AUDIO MUTE | ON/OFF切换声音暂停；OFF开始WAV读取与预填 | OFF |
| VOLUME DOWN | 每次确认减1，0静音、到0停止 | 08 |
| VOLUME UP | 每次确认加1，到31停止 | 08 |

若已静音需开声：长按KEY3开菜单，KEY2四次到AUDIO MUTE，短按KEY3并松开切OFF，长按退出。调音量先导航到DOWN/UP，再逐次短按KEY3确认；KEY1/2只导航。PLAY/PAUSE只开关图片轮播，SW仍控制图片效果。音量0继续消耗PCM，MUTE暂停PCM；本轮复位恢复不静音和08级。

例：长按KEY3打开菜单，从PLAY条目按KEY2一次到GAMMA，短按KEY3并松开开启；再短按关闭，比较同一张图片。想看诊断，从GAMMA按KEY2到DIAG，短按开启，再按KEY2到DIAG PAGE，逐次短按翻页。长按KEY3退出后，普通MODE保持进入菜单前的值。

菜单打开不会自动暂停轮播，想固定同一张图片比较效果，先关闭自动播放。SW四路在菜单内继续控制字幕、滚动和转场。菜单关闭时第三行G:0/1 D:0/1 P:0..3显示提亮、诊断开关和页号；画面设置在帧边界反映到OSD。数码管是10Hz慢速快照，不是实时波形记录。页码和十六进制位定义见[诊断说明](ONLINE_DEBUG_20261014.md)。

伽马是可选提亮效果，不是显示器色彩校准，已编码的照片可能发灰，建议默认关闭。所有设置存于寄存器，复位/断电不保留。详情见[本轮优化](BOARD_OPTIMIZATION_20261014.md)。

## 1. 先记住三个规则

1. **KEY3选择“现在调什么”，KEY1和KEY2执行对应操作。** 每次操作前，先看左上角第三行的 `MODE`。
2. **SW第1、2路控制字幕，第3、4路共同选择换图动画。** 拨到某个位置后保持，不需要一直按住。
3. **显示器接HDMI_B。** 本轮复位默认VGA；R可请求SVGA并受EDID限制，KEY和SW仍不用于手动选择分辨率。

KEY是按下后会弹回的按钮；SW是可以保持ON/OFF位置的拨码开关。下面的KEY1/2/3是代码名称，SW第1～4路按代码sw[0]～sw[3]编号，不能直接推断它们在实物板上从左到右的顺序。

| 本文名称 | 代码信号 | FPGA封装管脚 | 用途 |
|---|---|---|---|
| KEY1 | key1 | B2 | PLAY时下一张；调参时减小 |
| KEY2 | key2 | C1 | PLAY时开关自动播放；调参时增大 |
| KEY3 | key3 | B1 | 短按释放切换PLAY/BRIG/CONT；长按打开/关闭菜单 |
| 整机复位 | rst_n | A2 | 重新启动播放器 |
| SW第1路 | sw[0] | C8 | 字幕和右上运行时间显示开关 |
| SW第2路 | sw[1] | C7 | 字幕滚动开关 |
| SW第3路 | sw[2] | C6 | 转场选择低位 |
| SW第4路 | sw[3] | C5 | 转场选择高位 |

**B1、B2、C1是芯片封装坐标，不是板上按钮丝印或排针编号。** 若板上按钮名字不同，需要根据对应板卡原理图确认；不要将启动配置或电源开关当成这里的用户SW。官方例程已证实上述输入管脚，实物编号及ON方向仍需核对。

## 2. 开机后先看屏幕

先插好准备过的图片卡，将HDMI_B接到显示器，打开显示器并选中对应输入，再配置FPGA或复位。首次使用建议至少准备两张不同图片，便于观察换图和转场。图片准备方法见 [接线与制卡教程](CONNECTION_AND_USAGE.md)。

左上OSD字段可以这样理解（实际字符间距以画面为准）：

| 字段或示例 | 含义 | 操作时怎么看 |
|---|---|---|
| `SRC:1280X0720` | 原图宽1280、高720 | 表示原始BMP尺寸；首图确认前可能为0000 |
| `->800X600` | FPGA当前输出800×600 | 也可能是640×480，不是显示器面板原生分辨率 |
| `PLAY:OFF` / `PLAY:ON` | 自动播放关闭/开启 | 用它判断是否已暂停轮播 |
| `IMG` | 图片序号和找到的图片数量 | 不是文件名；加载时索引可能先变化 |
| `LOAD:B` | 正忙于加载或换帧 | 等待完成再发下一次换图操作 |
| `LOAD:-` | 当前无忙/错误标志 | 适合继续操作 |
| `LOAD:E` | 加载错误、读FIFO欠载或写/视频FIFO溢出状态 | 不是正常等待提示，见排障部分 |
| `BRI:+00` | 亮度为0 | `+16`更亮，`-16`更暗 |
| `CON:1.00` | 对比度为1倍 | 1.25更强，0.75更弱 |
| `MODE:PLAY` | KEY1/2当前用于播放 | KEY1下一张，KEY2开关轮播 |
| `MODE:BRIG` | KEY1/2当前用于亮度 | KEY1减亮度，KEY2加亮度 |
| `MODE:CONT` | KEY1/2当前用于对比度 | KEY1减对比度，KEY2加对比度 |
| `K3:MODE` | KEY3切换操作项 | K1/K2/K3分别就是KEY1/2/3 |

**`PLAY:ON/OFF`与`MODE:PLAY/BRIG/CONT`是两件事。** 前者说明是否轮播；后者说明两个按键现在控制什么。进入BRIG并不会自动暂停已经开启的轮播。

右上 `UP HH:MM:SS` 是播放器启动后的运行时长，不是北京时间。左上状态OSD由键盘O开关；右上时间和底部字幕由SW第1路一起开关。

## 3. KEY3：选择当前操作项

上电或整机复位后的默认操作项是PLAY。每按一次KEY3，循环切换一次：

```text
PLAY（播放） → BRIG（亮度） → CONT（对比度） → PLAY（播放）
```

菜单关闭时，KEY3短按本身不换图、不改变亮度或对比度。松开后观察第三行MODE及第四行操作提示，确认进入目标项，再按KEY1或KEY2。

| 当前MODE | KEY1按一次 | KEY2按一次 | KEY3按一次 |
|---|---|---|---|
| PLAY | 请求显示下一张 | 切换自动播放ON/OFF | 进入BRIG |
| BRIG | 亮度减8 | 亮度加8 | 进入CONT |
| CONT | 对比度减0.25 | 对比度加0.25 | 回到PLAY |

短按每次约0.1秒再松开即可，不需要快速连点。代码要求约20ms稳定按下、稳定释放；KEY1/2长按不连续增加或翻页，KEY3长按约1.1秒专门打开/关闭菜单。上电时若一直按住按钮，先松开，再重新按下。不要同时按多个按钮；本版没有组合键操作。

## 4. KEY1、KEY2：手动换图与自动轮播

### 手动显示下一张

1. 看MODE；如果不是PLAY，按KEY3直到出现 `MODE:PLAY`。
2. 若 `PLAY:ON`，按KEY2关闭自动播放，确认变为OFF，便于观察手动操作。
3. 等待 `LOAD:B` 消失，再按KEY1一次。
4. 新图片需要先读卡、缩放、写入备用帧缓存，期间旧图可以继续显示。
5. 新图准备好后，按照SW选择的转场方式切换。

最后一张之后循环回第一张。当前没有独立的“上一张”按键；要回前面的图片，可继续循环。只有一张图片时看不到不同内容的轮换。

加载忙时最多暂存一个“下一张”请求，多次连按不会逐次排队执行。为避免当前换图结束后又紧接着换一次，演示时等加载完成再按。

### 开启自动播放

1. 确认已找到至少两张图片，并且首图已经显示。
2. 确认 `MODE:PLAY`。
3. 按KEY2一次，观察 `PLAY:ON`。
4. 播放器在可换图时自动加载下一张，并循环播放。

自动播放不是严格每秒完成一次换图。实际间隔包括定时等待、读卡、缩放、缓存写入、帧边界等待和转场时间。图片尺寸、SD卡速度及所选效果都会影响观察到的间隔。

### 停止自动播放

先用KEY3回PLAY，再按KEY2，确认 `PLAY:OFF`。已经开始的加载或转场可能继续完成；关闭轮播不等于立即中断当前画面变化。不要在BRIG或CONT模式直接按KEY2期待停止轮播，那样会增大参数。

## 5. 调亮度：完整例子

亮度用于整体提亮或压暗图片。范围 **−64～+64**，默认 **0**，每次改变 **8**，到上下限后停止。

假设想把亮度从0调到+16：

1. 在PLAY模式用KEY2关闭轮播，选择一张照片并等待加载完成。
2. 按KEY3一次，确认 `MODE:BRIG`。
3. 按KEY2一次并松开，观察 `BRI:+08`。
4. 再按KEY2一次，观察 `BRI:+16`。
5. 想调回0，按KEY1两次，分别得到+08和+00。
6. 调好后按KEY3两次，经CONT返回PLAY。

想从0调暗到−16，则在BRIG模式按KEY1两次。参数跨时钟传送并在帧边界生效，按钮按下后可能有短暂等待。

亮度作用于图片层及其黑边；提高亮度后黑边变灰是当前处理顺序的预期效果。OSD和字幕后叠加，不会跟着照片一起变暗。

## 6. 调对比度：完整例子

对比度影响暗部与亮部的差别。大于1.00通常更强烈，小于1.00通常更平缓；过高时部分亮部或暗部可能丢失细节。

允许值为：`0.50、0.75、1.00、1.25、1.50、1.75、2.00`。默认 **1.00**，每次改变 **0.25**，到边界后停止。

假设想从1.00调到1.50：

1. 先暂停轮播，停在同一张照片上。
2. 从PLAY按KEY3两次，经BRIG进入 `MODE:CONT`。
3. 按KEY2一次，观察 `CON:1.25`。
4. 再按KEY2一次，观察 `CON:1.50`。
5. 想回1.00，按KEY1两次。
6. 按KEY3一次回PLAY。

切换MODE不会清除已调好的参数，换图片时也沿用设置。整机复位会恢复亮度0、对比度1.00，参数不保存到Flash，断电不保留。

## 7. SW第1路：显示或隐藏字幕与时间

| 位置 | 预期结果 |
|---|---|
| ON | 底部字幕条与右上运行时间显示 |
| OFF | 底部字幕条与右上运行时间一起隐藏 |

它不会关闭图片，也不会关闭左上状态OSD。隐藏字幕也不会关闭换图转场。

操作：先拨ON，观察底部黄色英文标语、半透明底条和右上运行时间；再拨OFF，观察两者隐藏而照片继续显示。

三条内置英文标语随图片索引选择，第4张回到第一条。SW不能输入新文字、选择字体或修改运行时间；当前没有任意文字输入功能。

## 8. SW第2路：让字幕滚动或停止

先将SW第1路设为ON，否则字幕隐藏，不容易观察效果。

| 第1路 | 第2路 | 预期结果 |
|---|---|---|
| ON | ON | 显示字幕并向左滚动 |
| ON | OFF | 显示字幕，停止在当前位置 |
| OFF | ON或OFF | 字幕和时间隐藏；字幕滚动位置暂停更新 |

第2路从OFF拨回ON后继续滚动。若切图导致标语内容改变，新标语会从起点开始，所以不能总期待换图后仍停在同一位置。暂停字幕不暂停图片轮播，也不停止右上运行时间计时。

## 9. SW第3、4路：选择换图片时的效果

两路必须一起看，只有四种组合：

| 第3路 | 第4路 | 换图方式 | 字幕顶部细线颜色（字幕显示时） |
|---|---|---|---|
| OFF | OFF | 直接切换 | 白色 |
| ON | OFF | 淡出淡入 | 橙色 |
| OFF | ON | 滑动 | 青色 |
| ON | ON | 淡出淡入、滑动交替 | 紫色 |

**拨动这两路只是选效果，不会立即换图片。** 拨好后等待约0.1秒，再在PLAY模式按KEY1，或开启自动播放，才能看到效果。首张图片直接显示，不展示一次完整换图动画。

淡出淡入：旧图逐渐变暗，黑场时换帧，新图逐渐变亮。滑动：旧图向右移出，黑场换帧，新图从右侧进入。当前效果经过黑场，不是两张图片同时交叉混合。

交替模式：复位后的第一次实际动画为淡出淡入，下一次为滑动，再下一次淡出淡入。首图不消耗轮次；暂时退出交替模式再回来会保留轮次。

改变拨码时当前正在执行的动画不会立即换类型，新选择用于后续转场。建议先暂停自动播放、拨好两路，再开始演示，避免在逐路拨动的中间位置触发其他效果。

## 10. 可以直接照着拨的组合

下面每一列都按本文定义的第1～4路，不代表实物从左到右。

| 想展示的效果 | 第1路 | 第2路 | 第3路 | 第4路 | 接下来怎么做 |
|---|---|---|---|---|---|
| 图片直接切换，不显示字幕时间 | OFF | OFF | OFF | OFF | PLAY下按KEY1 |
| 图片加静止字幕 | ON | OFF | OFF | OFF | 观察字幕；KEY1直接换图 |
| 滚动字幕加淡出淡入 | ON | ON | ON | OFF | PLAY下按KEY1或开启轮播 |
| 滚动字幕加滑动 | ON | ON | OFF | ON | PLAY下按KEY1或开启轮播 |
| 滚动字幕加交替转场 | ON | ON | ON | ON | 连续换两次图，观察两种效果 |
| 隐藏字幕，但保留淡出淡入 | OFF | OFF | ON | OFF | PLAY下按KEY1 |

“全部OFF”不会停止播放器，也不会关闭自动播放。自动播放由PLAY模式下的KEY2控制。

本工程将SW闭合到GND的低电平作为ON。若实物丝印方向与效果相反，需要核对板卡接线，不能仅凭开关朝向推断当前功能。开关和按钮稳定约20ms后才被接受，画面设置还需等待帧边界；操作后给屏幕一点响应时间。

## 11. 一次完整课堂演示

1. 下载当前自适应bit，HDMI_B接显示器，使用至少两张不同照片的图片卡。
2. SW第1、2、3路ON，第4路OFF。复位后等待首图显示。
3. 确认 `MODE:PLAY`、`PLAY:OFF`；看第一行输出为640×480或800×600。
4. 按KEY1，演示下一张与淡出淡入。等待加载和动画完成。
5. 第2路拨OFF，演示字幕静止；再拨ON，演示继续滚动。
6. 第1路拨OFF，演示字幕/时间隐藏、左上OSD保留；再拨ON。
7. 第3路OFF、第4路ON，等约0.1秒后按KEY1，演示滑动。
8. 第3、4路均ON，连续完成两次换图，演示交替转场。
9. 按KEY3进BRIG，按KEY2两次演示亮度+16，再按KEY1两次回0。
10. 按KEY3进CONT，按KEY2两次演示对比度1.50，再按KEY1两次回1.00。
11. 按KEY3回PLAY，按KEY2开启自动播放，确认 `PLAY:ON`。
12. 最后再次在PLAY模式按KEY2，确认 `PLAY:OFF`。

## 12. 复位与常见误操作

整机复位使用A2对应的复位输入，不能用KEY3代替。复位会重新识别显示器、初始化SD、扫描图片，亮度回0、对比度回1.00、操作项回PLAY，自动播放关闭，运行时间归零。SW的物理位置不会改变，启动稳定后重新读取实际拨码位置。

| 现象 | 先检查什么 | 怎么处理 |
|---|---|---|
| KEY1不换图，亮度却变了 | MODE是否BRIG | 用KEY3回PLAY再按KEY1 |
| KEY2按了仍在轮播，图片却更亮 | 当前是否处于调参项 | 回PLAY后按KEY2，确认PLAY:OFF |
| 按住KEY2，数值只变一次 | 本版没有长按连发 | 松开后重新按下，逐次调整 |
| 亮度/对比度不能继续加 | 是否达到+64或2.00 | 已到上限，按KEY1减小 |
| 拨第2路看不到字幕 | 第1路是否OFF | 先开启第1路 |
| 关闭字幕后左上文字仍在 | 左上是状态OSD | 当前设计常开，与字幕开关分开 |
| 拨转场开关，当前图片没动 | 只选择了下次效果 | PLAY下按KEY1发起换图 |
| 刚拨完就换图，效果不是预期 | 消抖/帧边界尚未接受，或当前转场已锁定 | 等待，暂停轮播后再选择并测试 |
| 自动播放无法打开 | 尚未扫描完或只有一张有效图片 | 等首图显示，并准备至少两张有效图片 |
| 连按多次没有对应次数的换图 | LOAD忙时操作不会无限排队 | 等LOAD忙结束，再按一次 |
| 复位后调整值消失 | 参数未持久保存 | 重新调节；这是当前预期行为 |
| 换显示器后模式没变 | 只在启动时识别EDID | 接好并打开显示器，再整机复位 |
| LOAD长时间为E | 可能有图片/读卡/换帧错误 | 查制卡与格式；返回PLAY后按恢复流程处理，必要时复位 |
| 全部按键都无反应 | 下载版本、按键管脚、复位状态或初始化状态 | 先核对本页bit链接、板卡映射及屏幕状态 |

当前KEY长按菜单可以调音量和静音；KEY/SW没有手动输出分辨率、任意文字输入和独立上一张功能。UART/红外控制禁用，不需要发送n/b/p/+/-等历史串口命令。
