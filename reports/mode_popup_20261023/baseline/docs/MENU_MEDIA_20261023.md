# 菜单切换图片、AVF视频、WAV及显示分辨率

> **先核对按键编号，避免误按复位。** 本页KEY1是代码`key1`、接B2；KEY2接C1；KEY3接B1。A2接`rst_n`，按下会整机复位熄屏。如果板上四键按官方key[0..3]顺序编号，实物第1键是复位，第2键才是本页KEY1，第4键才是本页KEY2。实际丝印请对照原理图；详见[按键/复位对照](KEY_RESET_MAPPING_20261023.md)。

本页对应2026-10-23新增的菜单媒体页。源码已接入且全量验证通过，[包含新功能的bit](../reports/menu_media_20261023/bitstream/video_improve_menu_media_20261023.bit)已生成（648248字节）；见[本轮验证记录](../reports/menu_media_20261023/RESULT.md)。原来纯色子菜单版bit没有本页新增功能。

## 打开、翻页和进入

1. 长按KEY3约一秒，打开贴左的纯色窄菜单。松开按键后再做下一次操作。
2. KEY1上移，KEY2下移；选中项为两倍黄色字。
3. 第一页保留八项：播放、亮度、对比度、伽马、音量、静音、诊断、退出。标题右侧显示页码1。
4. 从第一项“播放”按KEY1，可以直接到第二页最后一项“分辨率”；再按KEY1可依次回到音乐、视频、图片。也可以从第一页最后一项“退出”按KEY2到第二页“图片”。标题页码变为2。
5. 第二页四项：图片、视频、音乐、分辨率。末项按KEY2会回到第一页“播放”。菜单始终只显示名称一列，不会变宽。
6. 短按KEY3进入选中项的子菜单。进入本身不执行切换。
7. 子菜单短按KEY3返回列表；长按KEY3从任意菜单界面关闭。

## 下一张图片

选“图片”进入，界面显示“下一张”。按KEY1或KEY2执行一次：

- 当前已是相册模式：调用原来的下一张图片通路，从FAT32图片列表选择下一文件，末张后回到第一张。
- 当前是AVF视频模式：切换到相册/WAV模式并重新读卡，从该模式的首张图片开始；不会因为同时发下一张而跳过首张。
- 加载忙或列表为空时，不接受同类型的追加下一张请求。等当前画面稳定后再按；没有新增无限队列。

图片是工程现有支持的BMP格式，不是JPEG或PNG直接播放。子菜单执行键在按下后完成消抖才触发；一直按住只触发一次，下一次请松开再按。

## 下一个视频

选“视频”进入，显示“下一段”，按KEY1或KEY2执行：

- 当前已是AVF模式：沿现有AVF文件列表选择下一段视频，末段后回到第一段。
- 当前是相册/WAV模式：切到AVF模式、重新读卡，从第一段AVF开始。
- 切换模式会复位媒体链路，菜单会关闭，显示器可能短暂黑屏。要再次切换，请重新长按KEY3打开菜单。

视频使用原有AVF文件格式，不是直接解码MP4/H.264。SD/FAT32/AVF解码和帧缓存没有为菜单重新实现。文件列表空、读卡或文件本身错误，不能靠菜单变成可播放文件。

## 下一首WAV

选“音乐”进入，显示“下一首”，按KEY1或KEY2执行：

- 相册/WAV模式下：读取实际WAV列表位置，选择下一首，最后一首后回到第一首。图片仍由相册链路显示；它是相册的独立WAV音轨。
- AVF模式下：先切回相册/WAV模式，启动该模式的首个WAV。AVF模式播放的是视频自身的内嵌音轨，不会把独立WAV叠加到视频音轨上。
- 列表为空或图片/媒体路径正在忙时，同类型下一首请求不会排队，等待后再按。

独立WAV仍需满足原格式：PCM、16bit、单声道、48kHz。菜单没有放宽这个格式限制。听不到声音时，先检查“静音”为关、“音量”大于0，并检查WAV格式和显示器/音箱的HDMI音频支持。

## 修改显示分辨率

在相册/WAV模式，进入“分辨率”子菜单：

| 按键 | 作用 |
|---|---|
| KEY1 | 请求640×480 |
| KEY2 | 请求800×600 |
| KEY3短按 | 返回名称列表 |
| KEY3长按 | 关闭菜单 |

这里修改的是HDMI输出画幅，图片和菜单沿已有链路一起适配。子菜单显示**当前实际输出**尺寸，不把请求值当作已经生效的结果。

800×600需要显示器EDID明确支持该模式；不支持或EDID不可用时沿原逻辑回退640×480。切换期间先复位媒体/视频消费者，再切换既有像素与串行时钟，重新加载当前图片，可能短暂黑屏。不要在这时连续快速按键；等画面稳定后继续。

AVF视频目前输出固定640×480，因此在AVF模式下分辨率子菜单仍显示640×480，KEY1/KEY2不改变电影输出。想切800×600，请先使用“图片”或“音乐”进入相册模式。本次没有增加720p或1080p输出，也没有改变SD时钟。

## 原功能怎么用

第一页面的原功能仍按[原子菜单说明](MENU_SUBMENU_20261023.md)操作：进入后KEY1/KEY2减/增或切换，KEY3返回，长按关闭。

菜单外调整亮度或对比度，左上角两秒提示继续保留；连续实际变化会更新数值并重新计时。即使最后停留在第二页后关闭菜单，这个提示仍显示亮度/对比度，而不是误显示媒体菜单文字。

原KEY快捷模式、SW、PS/2、红外和UART对时沿原通路保留。媒体模式选择采用最后一次明确请求，旧的键盘或组合键保持电平不会锁死新菜单选择；KEY1+KEY2组合键的重复请求通过独立事件标记传递。
