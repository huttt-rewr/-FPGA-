# 本轮实施计划与约束核对

用户附件：2026-10-19《UART 上位机 + 红外遥控 + 画质增强 + 电子相册时钟》。
基线为3ffb71d；SWNS +0.116ns、HWNS +0.030ns、102项ModelSim。

四阶段分别完成静态检查、完整ModelSim、完整综合/布局布线/最终STA后，再推进下一阶段。

## 已核对的附件示例问题

1. 当前player_control默认b为上一张、p为自动播放切换，与新协议相反。用PC_COMMANDS参数选择新协议，保留默认旧语义和原测试。
2. T+6位字符必须检验HH=00..23、MM/SS=00..59，有超时和原子发布；时间包只返回一次K或?，包内字符不触发其它命令。
3. 对时时钟24小时回绕；原UP计时不被默认功能替换。BJ标签和时间数字一起在帧边界锁定。
4. 附件scale表写十进制，却用readmemh读取，数值会错。实际采用生成的十六进制表和可移植常量ROM，避免依赖TD/ModelSim的当前工作目录。
5. 自动色阶仅统计有效像素；空帧不能覆盖统计、恒色通道不除零、首个有效统计之前直通、开关在帧边界生效。
6. 新五秒定时器不能直接与原status_auto同时驱动next，否则会与既有fps_control重复换图。采用独立默认关的相册模式，在原自动轮播开启时暂停新定时器，保留F档/KEY2/空格语义。
7. 中文字库必须明确初始化未用字符，不能让仿真X或综合不定值进入画面；字体ROM延迟与RGB/XY/VS/DE同步。

原SD/FAT32/BMP/WAV/SDRAM、官方HDMI/IP、引脚/PLL/时序约束及70位status_source保持。
不自动打开COM口、不下载FPGA、不写实体TF卡；软件仿真通过与实板出图/出声/遥控验收分开记录。
