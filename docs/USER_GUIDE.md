## 硬件

**HDMI线接开发板 HDMI_B（HDMIB），另一端接显示器HDMI输入；本工程不使用HDMI_A。** 官方lab_ex4_tf/lab_ex5_i2s说明均指定B口，且当前工程与例程的HDMI管脚位置一致。接好并选择显示器输入源后复位，重新触发EDID读取。

EG4S20BG256，50MHz输入；启动时按EDID选择640×480（25MHz、约59.524Hz）或800×600（40MHz、约60.317Hz）。合封SDRAM为40MHz。不输出1080p，不支持运行中热插拔自动切换。

| 信号 | 管脚 |
|---|---|
| clk / rst_n | R7 / A2，低有效复位 |
| HDMI_CLK_P / 自动负端 | C3 / C2 |
| HDMI_D0_P / 自动负端 | G5 / G6 |
| HDMI_D1_P / 自动负端 | F1 / F2 |
| HDMI_D2_P / 自动负端 | E1 / D1 |
| DDC SCL / SDA | P2 / R2 |
| SD CLK / MISO | A14 / B14 |
| SD MOSI / CS | A13 / A12 |
| UART RX / TX（本版禁用） | F12 / D12 |
| SW第1～4路 | C8 / C7 / C6 / C5 |
| 参数选择key3 | B1 |
| NEC 输入 | D14 |
| key1 / key2 | B2 / C1 |

以 src/constraints/pin.adc 为准，仍需核对原理图。HDMI LVDS33_E / 8 mA 是候选，须验证电阻网络、供电、DDC 上拉和接收负载。官方IO手册虽有150Ω/150Ω/140Ω数据，但其负载是100Ω差分LVDS接收端，不能当本板HDMI装配指令。外接 UART/SD 使用匹配的 3.3 V 逻辑并共地。

## 从官方资料新确认的使用边界

- 板上合封SDRAM为8MiB；VGA两帧约2.344MiB，SVGA两帧约3.66MiB。64MiB是SD图片镜像/扫描范围，不是内存容量，也不是配置Flash容量。
- 当前配置目标是BG256，不能使用CG324的引脚表。JTAG专用脚已能从数据手册核对，但排针针序仍需板卡原理图，见 [接线教程](CONNECTION_AND_USAGE.md)。
- Bank1/3的3.3V供电要求是芯片要求，不是整板电源插座输入说明。IO手册的5V钳位示例不代表当前工程允许5V信号直连。
- `.bit`用于配置FPGA，本轮`.img`仅用于FAT32仿真卡；DUAL/MULTI BOOT描述配置Flash，本工程没有实现多启动功能。
- 当前时序及bit以 [构建状态](BUILD_STATUS.md) 为准。旧+0.118/+0.004ns只属于固定VGA版；内部removal不是HDMI管脚hold，未完成板级验收。

资料清单、页码和SDRAM/FIFO/PLL的具体问题见 [官方资料对照](VENDOR_REFERENCE_20261009.md)。

## 图片和存储卡

使用普通FAT32卡，根目录复制1～4张24位BI_RGB BMP和可选的48kHz/16bit/mono PCM WAV。仅8.3短名、根目录；按目录顺序取前4张BMP和第一个WAV。支持碎片，不要求连续扇区；不支持FAT16/exFAT/GPT。详细转换、复制和排障见[FAT32教程](FAT32_USAGE_20261015.md)。不执行旧pack/烧IMG流程。

## 首次运行

以下操作要求已经核对电气、完成构建/时序审查并生成匹配 bit；不要使用备份旧 bit 代表当前源码。

1. 插卡，连接 HDMI_B和下载器，无需串口。
2. 上电下载匹配 bit，释放复位。
3. 等待 PLL、卡初始化和扫描，无有效图片时可能耗时较长。
4. 首图写完后于场消隐提交；此前视频路径提供深蓝背景及可选 OSD，显示器锁定需实测。
5. 单图正确后测试多图、SW、自动播放和转场。

新图加载期间保留旧缓冲区，写完提交后切换。顶层按键消抖约20ms。自动播放约每秒提出请求，实际换图间隔还包含加载、场边界等待和所选转场。

## SW与按键操作

### 1. 先认清四路拨码

依据官方 `J:/DEMO/6_cnt10/cnt10.adc` 第21～24行，`8_key_sw/key_sw.adc` 使用相同四路输入。下面“第1～4路”按代码 sw[0]～sw[3] 定义，不保证是实物从左到右。板上印的是1～4还是0～3、ON方向和实际板卡版本仍需上板核对。

| 本手册编号 | 顶层信号 | FPGA管脚 | 功能 |
|---|---|---|---|
| 第1路 | sw[0] | C8 | ON：显示字幕条和右上运行时间；OFF：隐藏两者 |
| 第2路 | sw[1] | C7 | ON：标语向左滚动；OFF：停在当前位置 |
| 第3路 | sw[2] | C6 | 转场选择的低位，与第4路组合 |
| 第4路 | sw[3] | C5 | 转场选择的高位，与第3路组合 |

代码默认闭合到GND为ON，即低电平有效；断开时由上拉读取为OFF。官方例程确认了引脚与上拉，但没有完整板卡原理图证明你实物的ON丝印方向。若操作结果正好反向，先核对原理图或测量；正确修正点是 `switch_controls.v` 的 `ON_LEVEL` 参数，不要猜其他引脚。它支持逐位指定ON电平。

### 2. 转场怎么选

| 第3路 | 第4路 | 所选效果 | 字幕顶边颜色 |
|---|---|---|---|
| OFF | OFF | 直接切换 | 白色 |
| ON | OFF | 旧图淡出 → 黑场换图 → 新图淡入 | 橙色 |
| OFF | ON | 旧图右滑出 → 黑场换图 → 新图从右侧滑入 | 青色 |
| ON | ON | 淡出淡入与滑动交替，每次实际启动转场换一种 | 紫色 |

首张图片直接显示。交替模式复位后第一次动画是淡出淡入，下一次滑动；首图不消耗轮次。退出交替模式再回来保留轮次，整机复位才重置。选择模式不自动换图，要按下一张或启用自动播放才能看到动画。

转场开始时锁定模式。动画进行中改变拨码，当前动画继续完成，新选择用于下一次转场。第3、4路一起改时，先拨好、等至少约20ms稳定，再按换图；若自动播放正在运行，建议先暂停，防止在两次拨动之间启动中间模式。

### 3. 三个按键怎么用

| 按键（代码名） | FPGA管脚 | 操作 |
|---|---|---|
| key1 | B2 | PLAY：下一张；BRIG/CONT：减小参数 |
| key2 | C1 | PLAY：自动播放开/关；BRIG/CONT：增大参数 |
| key3 | B1 | 普通模式短按释放选PLAY/BRIG/CONT；长按约1.1秒开关菜单 |
| rst_n | A2 | 整机复位，重新初始化SD、扫描图片，运行时间归零 |

丝印名称不一定与代码key1/key2相同，以B2/C1对应的板载按键为准。菜单关闭时，PLAY状态按键保持超过约20ms后松开；B1短按释放切换PLAY/BRIG/CONT，长按进入菜单。等待LOAD忙状态结束再按下一次，忙时不会排入无限个请求。

### 4. 一次完整演示

1. 使用 [接线与制卡教程](CONNECTION_AND_USAGE.md) 把至少两张支持范围内的正高度24位BMP复制到普通FAT32卡根目录。详见[FAT32教程](FAT32_USAGE_20261015.md)。
2. 断电插卡，HDMI_B接显示器，选择对应HDMI输入，连接电源和下载器。
3. 第1、2、3路设ON，第4路设OFF：这表示字幕显示、文字滚动、淡出淡入。
4. 从构建状态页选择与功能匹配的候选bit，必要时按A2对应复位键。等待初始化、扫描和首张图显示。
5. 观察底部半透明蓝条、黄色英文标语、右上 `UP HH:MM:SS`。UP是复位后的运行时间，不是北京时间。
6. 第2路拨OFF：标语停止；再拨ON：从当前位置继续。隐藏期间滚动位置也停止，恢复后继续。
7. 第1路拨OFF：字幕和时间隐藏，左上状态仍显示；拨ON恢复。只拨第2路不会关闭字幕。
8. 按B2对应按键：加载新图完成后，旧图淡出、新图淡入，全程约1.1秒，读卡等待另计。
9. 第3路OFF、第4路ON，再按下一张：观察滑动。
10. 第3、4路均ON，连续换两次图片：依次观察淡出淡入和滑动。按C1对应按键可自动轮播，再按一次停止。

三条内置英文标语随图片序号选择：第1张WELCOME、第2张LEARN、第3张ENJOY、第4张回WELCOME。当前索引是控制端选择状态，可能在图片正式显示前变化；标语不是图片文件名。更换标语时滚动从起点开始。不支持任意文字输入或中文字库。



本版禁用UART/NEC控制，亮度−64～+64、对比度0.50～2.00可调；状态OSD常开、测试图关闭；WAV默认静音，可板载菜单解除。完整原理见 [SW手册](SW_CONTROLS_20261009.md)。

## 状态与异常

OSD左上角40列、4行，显示源分辨率、适配算法、PLAY/IMG/LOAD/EDID、BRI/CON和操作项。LOAD 的 B 表示忙、E 表示加载错误、读FIFO欠载或写/视频FIFO溢出、- 表示无上述标志；EDID Y 表示基础头、校验和及受支持的EDID版本有效；实际输出看第一行箭头右侧尺寸。

数码管：0 未就绪/复位，1 空闲，2 扫描/头部，3 帧写握手，4 读取像素。数字不证明 HDMI 显示正确。

单扇区约0.671秒无进度、SD命令/数据token错误，或可变尺寸整图加载约15秒超时，会中止不完整传输并复位SD链路。扫描未完成时，重新初始化后从头扫描；已有索引的加载失败时保留旧图和索引，重新初始化后按key1重试。更换内容不同的卡应整机复位以重建索引；不保证任意热插拔后自动播放新卡。

换帧请求发出后约5秒仍无确认，会报错并保持忙、禁止再写帧缓冲。真实迟到确认仍可完成换帧；若确认始终不来，需要整机复位。不能把超时当作换帧成功，也不会仅因超时释放缓冲区。

64 像素视频缓冲溢出后丢弃输入，到排空且遇场边界清除视频溢出标志并重新发 SOF。不保证加密核所有错误自动恢复。EDID 开始后约0.671秒没有新字节则结束并判无效，可在下一次开始信号后重新检查。

## 音频与排障

当前读取FAT32根目录第一个PCM WAV：48kHz/16bit/mono、≤16MiB，左右相同。先接HDMI_B和支持HDMI音频的显示器，再KEY3长按菜单→KEY2到AUDIO MUTE→KEY3短按确认OFF。VOLUME DOWN/UP需KEY3逐次确认调节。文件准备与复制步骤见[FAT32教程](FAT32_USAGE_20261015.md)，声音设置见[WAV音频手册](WAV_AUDIO_20261014.md)。

| 现象 | 优先核查 |
|---|---|
| 无 HDMI 信号 | 时钟、PLL、复位、管脚、电阻网络及模式兼容性 |
| 有背景无图 | 格式、扇区位置/连续性、扫描与 SDRAM 写入 |
| 图像异常 | 编码、连续扇区、SD 数据、帧缓存 |
| 初始化卡住 | 卡供电、接线、支持范围、复位 |
| LOAD 持续 E | 加载/提交错误或粘性FIFO故障；记录出现时机，按显示修复说明排查，必要时复位 |
| 无声 | FAT32版本配置、根目录WAV格式、AUDIO MUTE、VOLUME、A:E状态及显示器音频支持 |

修改后按 [README](../README.md) 运行静态检查、41项模块回归、必要的PLL回归与完整构建。当前时序以 [构建清单](../reports/build_manifest.json) 和 [屏幕适配记录](SCREEN_ADAPTATION_20261010.md) 为准，不沿用10月8日及更早数值。内部removal不是HDMI管脚hold；未执行实板兼容性、热稳定性或长期测试。
