# 键盘路线后续阶段：实现边界与待验证内容

本页说明本轮R/F实现机制与尚未完成的板级验收；正式接入和验证状态以构建状态为准。当前可用键位见[键盘手册](KEYBOARD_USAGE_20261016.md)，当前源码验证状态见[构建状态](BUILD_STATUS.md)。

## R：安全切换输出

独立 `video_mode_control` 在永久25MHz启动时钟域工作，接收一致性快照传来的 `res_mode`。它先令 `mode_ready=0`，等待各域同步复位已置位，再同时选择已有25/125MHz或40/200MHz像素/串行时钟组合，等待4096启动时钟周期后再释放SD、SDRAM读写和视频消费者。没有动态重配PLL，也没有用普通LUT切换时钟。

键盘与控制寄存器必须改用独立于 `mode_ready` 的复位，否则按R会复位自己的请求、回默认档而来回切换。音量、静音、图片/音频请求也应保留，播放器在新模式下重新挂载并重载当前选图；两块帧缓冲始终按最大800×600分配固定槽，不能用上一模式的像素计数提交新图。

EDID仅提供显示器是否支持800×600的能力。R选VGA时要能切回VGA；R选SVGA但EDID不支持时回退VGA，不能把EDID推荐SVGA和R请求直接做OR。00档为小素材缩放到VGA；不增加320×240HDMI时序，也不应取消已有任意合法图片缩放适配能力。

候选逻辑仿真已覆盖先复位再切时钟、VGA/SVGA往返、能力回退、切换期间追加请求和全局重启。额外端到端候选激励使用真实FAT/BMP/WAV，逐像素比较VGA/SVGA完整帧、返回当前图片，并在写图中途切档检查部分帧丢弃和重载。工程清单、跨域和整机STA的本轮结果见构建状态；实板显示器重新锁相验收仍未完成。

## F：目标换图频率

`fps_control`采用1/2/5/10/15/30档，定时器到期时若播放器忙则只保留一个待发请求，等提交完成后再发，不累计欠下的多次请求；超时置受限标志。读取、缩放、写帧及转场都可能限制换图速度，因此不能把25MHz的SD时钟或原始MB/s换算当作整机实际FPS。

显示应明确写 `TARGET:05` 之类目标值；出现L表示链路曾超过这一档的期限，需要降档或降低源图片尺寸。它不是显示器60Hz刷新率，也不是已经实测达到5FPS。纯定时器仿真覆盖各档周期、忙时截止等待、模式变化、不追赶连发以及暂停。

## SD四位与50MHz

正式板级工程仍为SPI25MHz。已完成的四位25MHz候选见[专门报告](SD_NATIVE_4BIT_20261016.md)，数据线上每根独立CRC16，命令CRC7、初始化、读扇区/FAT/播放器仿真可复用。官方手册PDF第20页已确认DAT1=B15、DAT2=A11和10kΩ上拉至3.3V；此前资料缺口已解除，仍须完成正式集成及板卡实物版本核对。

50MHz前必须进行CMD6检查及切换High Speed，读回切换状态，卡不支持时保持25MHz。100MHz主时钟的一半可提供50MHz线时钟，但读回采样窗口涉及卡的输出延迟、FPGA输入/输出延迟和PCB往返传播，不能把SDRAM的90度移相直接照搬到SD；需要卡协议时序预算、板级约束和示波器窗口验证。DDR50涉及1.8V与双沿I/O，本轮不做。六线映射资料已齐；正式集成与STA通过后可生成独立候选，但实物未测前不能宣称50MHz或≥10MB/s实体吞吐。
