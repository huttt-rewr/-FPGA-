# 键盘、分辨率和换图频率操作手册

> 2026-10-17当前：正式SD已切为原生四位25MHz，CLK=A14、CMD=A13、DAT0=B14、DAT1=B15、DAT2=A11、DAT3=A12，仍使用原TF卡槽；CMD/DAT外部10kΩ上拉依据已确认。KEY/SW/键盘操作不变。50MHz尚为隔离候选，未实板。准确验收见[构建状态](BUILD_STATUS.md)。下文SPI与未接入描述为历史记录。

本文说明本轮正式源码的操作。仿真、STA、候选bit与实板状态分别见[构建状态](BUILD_STATUS.md)，旧bit不能验证新增功能。

## 先接好设备

1. 断电，把显示器HDMI输入接开发板 **HDMI_B**。HDMI_A不用。
2. TF卡用FAT32；把BMP和WAV复制到根目录。BMP与WAV合计最多索引64份，不需要写裸扇区镜像。制卡见[FAT32教程](FAT32_USAGE_20261015.md)。
3. 使用支持PS/2 Set 2的键盘及板上匹配接口。官方两个例程的映射一致：CLK=M16、DATA=K16，LVCMOS33并上拉。它们是FPGA封装坐标，不是键盘插头的针号。USB键盘不能直接接D+/D−；被动转接头是否有效取决于键盘是否支持PS/2。
4. 打开显示器、选择对应HDMI输入，再上电或复位。板口供电与电平转换仍应按实物原理图核对。

PS/2接收器只接收按键，不发送配置命令、不控制键盘指示灯。键盘时钟约10～16kHz，经100MHz系统域同步、滤波、下降沿采样、奇校验和前缀处理，不作为FPGA内部逻辑时钟。

## 每个键怎么用

| 键 | 功能 | 具体操作 |
|---|---|---|
| →、← | 下一张、上一张图片 | 首尾循环，可遍历所有已索引图片；长按不连续跳图，松开再按 |
| 0～9 | 选前十张图片 | 0是第一张，9是第十张；OSD序号从1显示 |
| A，然后0～9 | 选前十份WAV | A松开后2秒内按数字，例如A、2选第三份；Esc取消 |
| 空格 | 自动换图开关 | 看PLAY:ON/OFF确认；与KEY菜单共用状态 |
| R | 循环请求输出模式 | 默认VGA → SVGA → 小素材/VGA → VGA；必须松开再按 |
| F | 循环目标换图频率 | 档位1、2、5、10、15、30，默认5；只影响自动换图 |
| ↑、↓ | 音量加、减 | 0～31，到边界停止；允许长按连发 |
| M | 静音切换 | 与KEY3菜单共用音频状态 |
| O | 状态OSD显示开关 | 在帧边界更新；独立字幕层仍由SW控制 |

不是两位数输入：连续按1、2是先选第二张，再选第三张，不是第12张。第11张以后的图片用左右方向键遍历；第11份以后的音频当前没有键盘直达操作。数字超出同类文件总数时回第一份；该类为空时不读取无效表项。

图片正在加载时，再选择会保留最新一条请求，等当前写帧/提交完成再处理。切换WAV会先取消旧音频流、排空已经发起的SD事务、清PCM队列和FIR/回声历史，再重新解析新WAV。短暂静音正常，图片路径不因此重新挂载。HDMI音频采样调度在切音频时保持，切分辨率则会复位整条视频/音频链路。

## R切分辨率，屏幕为何会暂黑

| 请求档 | 实际HDMI输出 | 使用说明 |
|---|---|---|
| 1：VGA，复位默认 | 640×480，25MHz像素，约59.524Hz | 全部合规图片都可缩放显示 |
| 2：SVGA | EDID支持时800×600，40MHz像素，约60.317Hz；否则回退VGA | OSD头部箭头后显示实际输出 |
| 0：小素材/VGA | 640×480 | 320×240图片可放大；仍兼容其他合法尺寸 |

0档和1档使用相同HDMI时序；0档不自动生成或预先压缩一份320×240图片，也不降低大图的SD读取量。要节省卡带宽，需事先把素材转换为320×240再复制到卡。本版保留任意合法尺寸适配能力，没有强制某档只读某种宽高。**没有320×240 HDMI输出，也没有1080p输出。**

OSD中的`R:0/1/2`显示请求档，箭头后尺寸显示实际输出；例如`R:2`而箭头仍为640×480，表示SVGA请求回退为VGA。这样也能区分输出时序相同的0档与1档。

按R后控制器先令各媒体/视频域复位，安静等待16个启动时钟，切换专用全局时钟选择器，再等待4096个25MHz启动时钟周期后释放各域。之后重新挂载FAT32、重载所选图片，并重新预填音频队列；显示器也需要重新锁定输入。旧模式的半帧不会直接提交到新尺寸帧缓冲。

键盘、音量、静音、OSD及选择寄存器使用独立复位，不会因为按R而把R请求清回默认。播放器重新挂载会暂停自动轮播，恢复画面后再按空格开启。全局复位和看门狗重启仍恢复默认设置。

EDID只提供能力，不能把“支持SVGA”直接OR进时钟选择；否则用户永远切不回VGA。没有新增PLL、没有动态写PLL寄存器。运行中热插拔并不重新协商EDID；换显示器应接好后复位。

## F调的是什么

默认TARGET:05，按F依次为10、15、30、1、2、5。空格先开启轮播，F才会影响换图。只按F而PLAY为OFF时，当前图不变。

TARGET是目标换图次数/秒；显示器刷新率仍约60Hz。读取、缩放、写帧、帧边界提交和转场都会花时间。定时器包含加载时间，到期但播放器仍忙时只等待一次；空闲后发一个请求，不追赶补发一串。实际换图速度受整个链路限制，不能保证TARGET:30就是30FPS。

TARGET右边的L表示启用该档后曾因加载/提交忙而错过期限。换档或暂停会清除该记录。遇L可降低目标档，或使用更小的BMP；本版没有根据文件大小虚构一个“精确可达帧率”。

## OSD读法与音频限制

- `SRC:0320X0240 ->640X480`：左侧原图尺寸，右侧实际输出。
- `IMG:10/12 AUD:03/03`：第10/12张图片，第3/3份音频。`00/00`表示该类为空。
- 文件行末尾T：超过BMP+WAV总64项限制，其余未索引。
- `LOAD:B`：忙；`LOAD:E`：加载或帧缓存诊断错误。
- `A:R`：WAV已解析；`A:M`：静音；`A:E1..E4`：音频失败原因。错误历史保持到真实PCM恢复，不随每秒重试闪灭。
- `U1`：本次视频域复位以来发生过音频欠载，换WAV不会清除，切视频模式或整机复位会清除。
- 右上`UP`是本次视频链路运行时间，不是实时时钟；切R模式会重新计时。

WAV仍限 **48kHz、16bit、单声道PCM**，不支持MP3、浮点WAV、立体声或44.1kHz。新顶层默认不静音、音量08，音量0也无声；开启可选回声profile时，静音和音量0也会屏蔽并清除旧回声历史。显示器需支持HDMI音频且自身未静音；有画面不等于一定有扬声器。出声最终需实板确认。

## KEY和SW仍然能用

KEY3短按并松开，PLAY→BRIG→CONT；长按约1.1秒开/关菜单。PLAY时KEY1下一张、KEY2开关轮播；BRIG时KEY1减亮度8、KEY2加8；CONT时KEY1减对比度0.25、KEY2加0.25。菜单内KEY1上、KEY2下、KEY3短按确认。

SW第1路控制字幕/运行时间，第2路控制滚动，第3/4路选择直切、淡出淡入、滑动或交替转场。拨码保持位置即可；实物ON方向、顺序必须按板卡确认。详细接线、模式和菜单表见[KEY/SW教程](KEY_SW_OPERATION.md)。

## 如何仿真与验收

在E:/fpga运行：

```powershell
python scripts/static_check.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_tests.ps1
python scripts/run_build.py
```

专项可用`run_keyboard_tests.ps1`与`run_indexed_tests.ps1`，全量回归另含模式控制、切模式重载、各档定时器、真实播放器自动换图和切源清音效。源文件登记进两个TD工程及design_files；原70bit状态总线位宽/位序保留，媒体/换图档位分别用独立一致性快照跨域。

SD正式接口仍是SPI25MHz，不是四位50MHz。四位25MHz协议候选及其模型吞吐不能当成实板结果；官方手册已确认六线映射和10kΩ上拉，正式四位集成、50MHz CMD6协商/板级时序签核仍未完成，见[SD候选说明](SD_NATIVE_4BIT_20261016.md)。
