## UART 命令（四阶段完整源码）

115200 波特，8 数据位，无校验，1 停止位；发送 ASCII 字符，不附加回车换行。

| 发送内容 | 操作 | 回显 |
|---|---|---|
| `n` | 请求下一张图片 | `K` |
| `p` | 请求上一张图片 | `K` |
| `b` | 切换既有自动播放状态 | `K` |
| `a` | 切换自动色阶 | `K` |
| s | 开关独立五秒相册轮播；复位默认关 | K |
| h | 开关固定中文点阵字幕；复位默认关 | K |
| l | 大字/原小字时钟切换；复位默认小字 | K |
| `T123456` | 把北京本地时间设为 12:34:56 | 完整七字节仅回复一次 `K` |
| 未知命令、非法时间、半包超时 | 拒绝本条命令 | `?` |

`K` 只表示命令已识别，不保证 SD 图片已加载或已完成换帧。`b` 是切换，不是幂等的“强制暂停”。`T` 后的六位必须为有效 HHMMSS：小时 00–23，分秒 00–59。相邻字节超过 0.5 秒会放弃半包；包内字符不会触发下一张或上一张。

没有收到对时命令时，原 `UP` 开机计时不变；首次对时后，字幕时钟改为 `BJ`，按 24 小时回绕。接收完成后通过独立 33 位 `cdc_snapshot` 发布；时间数字和标签在帧边界一起更新，避免半帧切换。先打开原 SW 字幕开关才能看到字幕时钟；对时不会强制改变 SW 设置。它没有 RTC、电池或网络授时，断电不会保存时间，精度受板上晶振影响。

## PC 脚本（没有自动打开实体串口）

`scripts/album_remote.py` 只有显式运行才会打开指定端口。需要在 PC 安装 `pyserial`，先查出实际串口号：

```powershell
python scripts/album_remote.py --help
python scripts/album_remote.py --port COM3 --command n
python scripts/album_remote.py --port COM3 --command a
python scripts/album_remote.py --port COM3 --time 123456
python scripts/album_remote.py --port COM3 --sync
```

`--sync` 每秒发送北京时间，使用 UTC+8 转换，不依赖电脑当前显示时区；Ctrl+C 停止。回显不是 `K` 或等待超时会报错。不要同时让多个程序占用串口；串口助手应关闭自动追加 CR/LF。

主机按“发送一条、等待一次回显”操作。应答队列是有界的；不要持续灌入无间隙命令并假定无限缓存。队列溢出会进入现有错误汇总，复位后清除。

## 已知引脚与接线边界

现有约束为 FPGA RX=F12、TX=D12，使用 LVCMOS33。UART 对照早前官方 `16_uart_rs232` 例程核对过包脚，**包脚名称不是板上排针编号**。必须按本板原理图确认对应连接点。若使用外置 USB-TTL：适配器 TX 接 FPGA RX，RX 接 FPGA TX，GND 共地，逻辑电平为 3.3V；RS-232 正负电压不能直接接 FPGA。板上已有转换器时，按其接法使用，不并接两个 TX 驱动。

IR 输入约束 D14，空闲高，接的是 NEC 38kHz 接收头解调后的数字基带；不能直接接裸红外光电二极管。现有资料仍注明 D14 接线待本板核实，不能据此声称板上已经有接收头。本轮没有实际接线、打开 COM 口、下载 FPGA 或写 TF 卡。

## 红外按键

| NEC命令码 | 操作 |
|---|---|
| `0x40` | 下一张 |
| `0x15` | 上一张 |
| `0x44` | 切换既有自动播放 |

这里列的是解调后的NEC命令字节，不是遥控器按键上印刷的数字。具体遥控器可能使用不同码表，必须先核对。长按产生的NEC重复码被忽略，防止自动播放反复开关；音量、静音等其他IR码目前不会改变系统，避免与原KEY菜单产生第二套参数。UART与IR恰好同拍时，完整的UART单字节命令优先；IR不生成UART回显。

## 自动色阶原理与局限

它在gamma之后、转场之前统计每帧有效像素的RGB最小值和最大值，下一帧按通道应用 `(C-min)*255/(max-min)`。实际用Q8倒数表、乘法、舍入和饱和实现，系数表使用一致的十六进制常量，避开示例中十进制文件被readmemh当作十六进制的错误。数据经过四级寄存器，RGB、VS、DE、XY延迟一致。

倒数表已改为三路同步BRAM：第一拍计算差值并寄存范围，第二拍取倒数，第三拍乘法，第四拍舍入/饱和输出。画质阶段的组合表改为同步ROM后，整机综合LUT曾从16641降至16299，使用3块额外BRAM，3个画质乘法DSP保持；原256范围×256输入参考和四拍延迟测试通过。这是该局部优化的对照值，完整相册版本的最终资源见后面的物理验收记录。

默认关闭；发送一次`a`开启，再发一次关闭，状态在帧边界锁存。开启后第一帧尚无有效统计时直通；恒色通道不做除零，空帧保留旧系数。关闭时有效像素逐值直通，只有整体流水延迟改变。它是动态范围拉伸，不是显示器色彩校准或自动曝光；逐通道处理可能改变色相，换图后第一帧可能沿用上一张统计，遇到本来就含0/255的照片改善很小。

## 五秒相册：一步一步使用

1. TF卡至少准备两张合规BMP，等待首图显示且LOAD不再为B。显示器接HDMI_B。
2. 先看PLAY:OFF。若原自动播放为ON，用KEY2（MODE:PLAY）、空格或串口b切到OFF。
3. 串口发送s，收到K后开启独立五秒计时。它从启用且首图就绪开始计时，每五秒产生一次下一张请求。
4. 读卡/加载忙或错误期间不积压连续请求；定时到期只保留一次待处理请求。加载、帧边界、转场还要时间，不能承诺照片严格每五秒完成一次切换。
5. 再发送s关闭。若同时开启原有自动播放，五秒调度暂停并清计数，原目标换图频率F继续有效；关闭原轮播后，五秒计时从头开始。

s状态独立于原PLAY标志。PLAY:OFF不能单独证明五秒相册关闭；当前OSD没有新增s状态灯。演示前复位把所有新增选项恢复为关闭。b和s都是切换命令，回显丢失时盲目重发可能反向切换。原KEY/SW仍控制原功能，未增加隐藏组合按键。

## 时钟、中文和画质：推荐演示步骤

先将SW第1路拨到字幕开启，再发送T123456，可见BJ 12:34:56并继续走秒；没有对时则显示UP开机时长。发送l把右上小钟移为画面上部的大字钟，再发l恢复小钟。l只选择样式，SW第1路仍是时钟和原英文字幕的总开关。

发送h出现“欢迎光临电子相册参赛作品多媒体展示”，再发h关闭。中文是固定17字、16×16同步点阵ROM，未用字模清零，不支持通过UART输入任意中文。中文层独立于SW英文字幕开关和键盘O状态OSD开关。逻辑640×480视口中，中文区域为x32～303、y384～399；在800×600时随已有视口映射放大为20×20字格。

大钟背景窗口为逻辑x144～495、y96～159；原小钟为x448～623、y16～47。字符采用5×7字模，大钟像素放大4倍，小钟2倍，在800×600再随视口适配。尺寸/开关和时钟数字在帧边界锁存。中文层增加两拍，自动色阶增加四拍，RGB/VS/DE/XY一起延迟。

固定一张灰暗、低对比度图片，发送a比较自动色阶。它作用于图片层，不处理之后叠加的文字；暗部伽马仍由原KEY菜单独立控制。全部叠加最后可能被G游戏画面覆盖，检查相册效果时先退出游戏。

PC端例子（COM3必须换成实际端口）：

```powershell
python scripts/album_remote.py --port COM3 --command a
python scripts/album_remote.py --port COM3 --command h
python scripts/album_remote.py --port COM3 --command l
python scripts/album_remote.py --port COM3 --command s
python scripts/album_remote.py --port COM3 --sync
```
