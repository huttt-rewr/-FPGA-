## 1. 先看：到底接哪些东西

```text
电脑 USB ── 板载下载 USB 或兼容下载器 ── FPGA 下载接口
开发板 HDMI_B ── HDMI 线 ── 显示器 HDMI 输入
制好的 TF/microSD 卡 ── 开发板 TF 卡座
匹配的电源 ── 开发板规定的电源输入
```

### 1.1 准备物品

| 物品 | 用途 | 说明 |
|---|---|---|
| HX4S20C板及匹配电源 | 运行电路 | 电源输入电压、极性按板卡手册 |
| HDMI线、显示器/电视 | 显示图片、接收WAV音频 | 有扬声器且支持HDMI音频才能听声音 |
| TF/microSD卡、USB读卡器 | 图片存储及电脑制卡 | 首次用可清空的测试卡 |
| 兼容下载器或板载下载接口 | 配置FPGA | 普通串口转换器不能替代 |
| 板卡原理图、万用表 | 确认排针网络、供电与共地 | 外接排针时需要 |

### 1.2 三种“端口号”不要混淆

- **F12、D12、A14**：FPGA芯片封装管脚坐标，不是排针第12/14针。
- **J1、J2、P1等**：电路板连接器编号，需要查看对应版本原理图。
- **COM3、COM8等**：电脑给USB串口分配的编号，与FPGA管脚无关。

目前源码能确认FPGA管脚，但没有足够资料确认你这块板的USB插座分工、J1/J2具体编号、排针方向和第几针。下文给出网络名和管脚坐标；落到实物排针时，应从原理图追踪对应网络，不能凭位置猜测。

## 2. 电源和下载线怎么接

1. 连接外部模块前先关闭开发板电源。
2. 找板卡手册规定的电源输入，确认电压、极性与供电方式。IO使用3.3 V不等于整板电源插座应输入3.3 V。
3. 下载线接板载下载USB，或通过兼容下载器连接板载JTAG口。不要把USB-UART接到JTAG排针。
4. 外接JTAG时，TCK/TMS/TDI/TDO/GND/VREF的排列按板卡与下载器两份手册核对。`pin.adc`不定义专用配置管脚，不能从用户IO表推导JTAG针序。
5. 多个USB口的用途以丝印和原理图为准。出现COM口说明有串口功能，不能单凭这一点断定该口能下载FPGA。

本工程没有UART配置加载器，不能把 `.bit` 当文本通过串口发送。普通临时FPGA配置通常断电丢失；上电自动运行需要另行确认板上配置Flash、启动模式和工具支持的烧写文件格式。

### 2.1 新资料能确认的JTAG封装脚

官方《EG4S20数据手册》PDF16–19的BG256表给出：

| 信号 | FPGA封装坐标 | 连接时怎么用 |
|---|---|---|
| TDI / TCK | C12 / C14 | 在原理图上追踪到JTAG座子，再核对下载器针序 |
| TDO / TMS | E14 / A15 | 不能把坐标当排针编号或凭相邻位置接线 |
| DONE | P13 | 配置完成相关脚，不能据此保证板上某个LED就是DONE |
| PROGRAM_B / INIT_B | T2 / R3 | 配置控制脚；与本工程A2上的用户复位不同 |
| M0 / M1 | T11 / N11 | 启动模式脚；跳帽怎么设需对应板卡说明 |

不要拿CG324封装表查BG256。供电注释在PDF21顶部：VCCIO1、VCCIO3、VCCAUX内部相连，Bank1/3电源为3.3V。此信息用于原理图核查，不是改整板电源输入的操作。UART的F12/D12在Bank0，仍需核对板上供电和电平。

## 3. HDMI 接哪个口

**接开发板丝印 HDMI_B（HDMIB）的插座，本工程不使用 HDMI_A。** 连接：开发板 **HDMI_B** → HDMI线 → 显示器 **HDMI IN**。显示器菜单选择实际接线的HDMI 1/HDMI 2输入源。普通笔记本HDMI口通常是输出口，不能直接作为本工程的显示输入。

依据：本机官方 `J:/lab_ex4_tf/代码说明.md` 第63行明确要求HDMI_B；`J:/lab_ex5_i2s/设计参考例程文档.md` 第116行也说明视频和音频经HDMI_B输出。两个例程的有效管脚约束均是CLK=C3、D0=G5、D1=F1、D2=E1、DDC SCL=P2/SDA=R2，与当前工程的位置对应。本结论只确认本工程使用B口，不推断A口在其他例程中的用途，也不等于已完成板级电气验证。

使用板载HDMI插座时，TMDS差分线和DDC线由PCB连接，不需要再用杜邦线逐根接。不要把芯片管脚直接拼接到裸HDMI插座作为已验证方案；当前HDMI电阻网络、共模、电平和DDC负载还需要原理图及实测核对。

声音也走这根HDMI线。当前没有必须接的模拟音频口或外部I2S口。HDMI转DVI可能只有图像，不能用它判断音频是否正常。

顶层没有HPD输入；启动时可按EDID在640×480/800×600之间选择。EDID由固定启动时钟上的一次脉冲触发读取；如果开机后才接显示器或更换显示器，应接好、选好输入源后整机复位，重新开始检测。

### 3.1 为什么手册里有电阻值，仍不能直接改板

官方IO指南PDF9–10列有Rs=150Ω、Rp=140Ω、483mV，条件为8mA驱动和接收端100Ω差分终端。它是伪LVDS的说明，不是本板HDMI电阻实装记录。HDMI的TMDS终端、共模和DDC上拉需另外核对；使用板载HDMI_B时不应再随意外加一套电阻。

IO指南PDF11–15的“兼容5V输入”还要求特定串阻、钳位和供电条件，且芯片启动前钳位未启用。因此外接UART/红外仍按3.3V TTL连接，不能因为手册有5V章节就直接接5V输出。原文位置和适用限制见 [官方资料对照](VENDOR_REFERENCE_20261009.md)。

## 4. TF 卡接哪里

优先把制好的卡插到开发板板载TF/microSD卡座；方向按实物卡座结构，不根据文件夹里的图片猜方向。插拔前关闭板电源。

如果确实使用外接卡模块，下表是信号关系，**不是模块排针从左到右的顺序**：

| 卡模块标识 | FPGA顶层信号 | FPGA管脚 | 方向（以FPGA为中心） |
|---|---|---|---|
| SCK / CLK | `sd_dclk` | A14 | 输出到卡 |
| MOSI / DI / CMD | `sd_mosi` | A13 | 输出到卡 |
| MISO / DO / DAT0 | `sd_miso` | B14 | 从卡输入 |
| CS / SS / DAT3 | `sd_ncs` | A12 | 输出，低有效 |
| GND | 板上GND | 查板卡GND端 | 共地 |
| VCC | 模块供电 | 查模块手册 | 与逻辑电平分别核对 |

裸microSD卡使用3.3 V供电；带稳压器/电平转换的模块可能有不同VCC要求，不能用“5 V模块”推断它的MISO一定适合FPGA。信号应为3.3 V兼容电平。不要让外接模块与板载卡座同时争用这些线。

## 5. 板载拨码和按键

### 1. 先认清四路拨码

依据官方 `J:/DEMO/6_cnt10/cnt10.adc` 第21～24行，`8_key_sw/key_sw.adc` 使用相同四路输入。下面“第1～4路”按代码 sw[0]～sw[3] 定义，不保证是实物从左到右。板上印的是1～4还是0～3、ON方向和实际板卡版本仍需上板核对。

| 本手册编号 | 顶层信号 | FPGA管脚 | 功能 |
|---|---|---|---|
| 第1路 | sw[0] | C8 | ON：显示字幕条和右上运行时间；OFF：隐藏两者 |
| 第2路 | sw[1] | C7 | ON：标语向左滚动；OFF：停在当前位置 |
| 第3路 | sw[2] | C6 | 转场选择的低位，与第4路组合 |
| 第4路 | sw[3] | C5 | 转场选择的高位，与第3路组合 |

代码默认闭合到GND为ON，即低电平有效；断开时由上拉读取为OFF。官方例程确认了引脚与上拉，但没有完整板卡原理图证明你实物的ON丝印方向。若操作结果正好反向，先核对原理图或测量；正确修正点是 `switch_controls.v` 的 `ON_LEVEL` 参数，不要猜其他引脚。它支持逐位指定ON电平。

### 2. 转场怎么选

| 第3路 | 第4路 | 所选效果 | 字幕顶边颜色 |
|---|---|---|---|
| OFF | OFF | 直接切换 | 白色 |
| ON | OFF | 旧图淡出 → 黑场换图 → 新图淡入 | 橙色 |
| OFF | ON | 旧图右滑出 → 黑场换图 → 新图从右侧滑入 | 青色 |
| ON | ON | 淡出淡入与滑动交替，每次实际启动转场换一种 | 紫色 |

首张图片直接显示。交替模式复位后第一次动画是淡出淡入，下一次滑动；首图不消耗轮次。退出交替模式再回来保留轮次，整机复位才重置。选择模式不自动换图，要按下一张或启用自动播放才能看到动画。

转场开始时锁定模式。动画进行中改变拨码，当前动画继续完成，新选择用于下一次转场。第3、4路一起改时，先拨好、等至少约20ms稳定，再按换图；若自动播放正在运行，建议先暂停，防止在两次拨动之间启动中间模式。

### 3. 两个按键怎么用

| 按键（代码名） | FPGA管脚 | 操作 |
|---|---|---|
| key1 | B2 | PLAY：下一张；BRIG/CONT：减小参数 |
| key2 | C1 | PLAY：自动播放开/关；BRIG/CONT：增大参数 |
| key3 | B1 | 循环选择PLAY、BRIG亮度、CONT对比度 |
| rst_n | A2 | 整机复位，重新初始化SD、扫描图片，运行时间归零 |

丝印名称不一定与代码key1/key2相同，以B2/C1对应的板载按键为准。菜单关闭时，PLAY按键保持超过约20ms后松开；B1短按释放切换PLAY/BRIG/CONT，长按约1.1秒打开菜单，KEY1/2不连发。等待LOAD忙状态结束再按下一次，忙时不会排入无限个请求。

### 4. 一次完整演示

1. 使用 [接线与制卡教程](CONNECTION_AND_USAGE.md) 把至少两张支持范围内的正高度24位BMP复制到普通FAT32卡根目录。详见[FAT32教程](FAT32_USAGE_20261015.md)。
2. 断电插卡，HDMI_B接显示器，选择对应HDMI输入，连接电源和下载器。
3. 第1、2、3路设ON，第4路设OFF：这表示字幕显示、文字滚动、淡出淡入。
4. 从构建状态页下载本轮显示修复bit，必要时按A2对应复位键。等待初始化、扫描和首张图显示。
5. 观察底部半透明蓝条、黄色英文标语、右上 `UP HH:MM:SS`。UP是复位后的运行时间，不是北京时间。
6. 第2路拨OFF：标语停止；再拨ON：从当前位置继续。隐藏期间滚动位置也停止，恢复后继续。
7. 第1路拨OFF：字幕和时间隐藏，左上状态仍显示；拨ON恢复。只拨第2路不会关闭字幕。
8. 按B2对应按键：加载新图完成后，旧图淡出、新图淡入，全程约1.1秒，读卡等待另计。
9. 第3路OFF、第4路ON，再按下一张：观察滑动。
10. 第3、4路均ON，连续换两次图片：依次观察淡出淡入和滑动。按C1对应按键可自动轮播，再按一次停止。

三条内置英文标语随图片序号选择：第1张WELCOME、第2张LEARN、第3张ENJOY、第4张回WELCOME。当前索引是控制端选择状态，可能在图片正式显示前变化；标语不是图片文件名。更换标语时滚动从起点开始。不支持任意文字输入或中文字库。

## 7. 把照片做成 FPGA 能读的卡

确认卡为FAT32、512字节扇区。用`prepare_media.py convert/check`生成并检查BMP，用`prepare_audio.py convert/check`准备可选WAV；然后在资源管理器中直接复制到卡根目录、安全弹出、插回TF卡座并复位。

文件建议命名`1.BMP`、`2.BMP`、`SOUND.WAV`，主体≤8个英文/数字字符；按目录顺序取前4个BMP和首个WAV。图片格式、尺寸范围与之前一致，音频仍只支持48kHz/16bit/mono PCM。**本版不烧写裸镜像，不需要固定64MiB地址。**完整步骤见[FAT32拷贝文件教程](FAT32_USAGE_20261015.md)。

### 8.2 检查和构建

### 8.4 配置到板卡

1. 供电并正确连接兼容下载器，确认驱动。
2. 在配套安路下载工具连接设备、扫描链路，确认识别到正确器件。菜单名称随工具版本变化。
3. 首次实验优先选择临时配置FPGA，载入刚生成且已核对的候选bit；不要选备份或队友目录的旧文件。
4. 等工具报告配置成功，随后按复位再观察功能。
5. 配置成功只证明配置链路完成，不证明SDRAM/HDMI都正确。

要固化到Flash，必须另行确认Flash型号、启动模式、拨码和工具要求的文件格式；这些板卡信息尚未确认，不能把上述临时配置步骤当成固化教程。

### 8.5 配置Flash、SD图片与多启动的区别

通过JTAG加载FPGA配置，与把图片镜像写入TF卡是两条独立流程。SD卡有图片并不代表FPGA已配置；FPGA配置完成也不代表卡的扇区布局正确。

J盘DUAL BOOT指南讲配置Flash中的primary/golden位流，MULTI BOOT指南讲由EG_LOGIC_MBOOT重新加载另一套电路。当前项目没有实现这些启动控制。只有核实本板Flash型号、容量、启动模式和TD下载方式后才能制定掉电保存流程，不能把手册示例地址、AP106板的J8或64MiB图片镜像用于配置Flash。

## 9. 第一次启动：按这个顺序观察

1. 断电插好测试卡、接HDMI到已开机显示器，选好输入源。
2. 接下载线；字幕、滚动用第1、2路SW，转场用第3、4路。无需串口。
3. 上电配置候选bit，释放复位。
4. PLL就绪后视频工作，第一张图提交前设计选择深蓝背景 `0x102438` 并可叠加OSD；显示器实际锁定仍待实测。
5. SD初始化、扫描、首次加载依次进行。找到足够图片或达到扫描上限后才开始首图；IMG数值变化不代表已写完。
6. 首图写入SDRAM后在场消隐提交，看到完整图再测试下一张。
7. 先用第1路SW检查字幕显示/隐藏；字幕正常但图片不出时，检查卡格式、扫描状态和SDRAM。当前未开放测试图控制。
8. 单图正常后测多图、自动播放、四种模式和滚动暂停；等一次操作结束再继续。

换了内容不同的卡，应整机复位重扫。重新初始化SD并不保证丢弃之前已保存的图片地址。

## 10. 操作速查

使用 [缩放与调参详细手册](SCALING_AND_PICTURE_CONTROLS_20261010.md)。第1路字幕，第2路滚动，第3/4路选转场；PLAY状态B2下一张，C1自动播放。B1循环选PLAY/BRIG/CONT；调参状态B2减、C1加，长按不重复。亮度−64～+64，对比度0.50～2.00。串口/红外禁用，OSD常开、测试图关闭；WAV默认静音，菜单可解除。

## 11. 屏幕和数码管状态怎么看

OSD在左上约(16,16)起，40列×4行：

| 字段 | 含义 | 不能由它推断的结论 |
|---|---|---|
| PLAY ON/OFF | 自动播放状态 | 视频时钟是否停止 |
| IMG 当前/总数 | 图片索引和已识别数量 | 扫描中或提交前不证明已有完整图 |
| LOAD B | 加载或等待提交确认 | SD仍在持续返回数据 |
| LOAD E | 加载、读FIFO欠载、写/视频FIFO溢出汇总错误 | 具体哪个模块有错 |
| LOAD - | 没有上述忙/错误指示 | 整机与电气已验证 |
| EDID Y | 基础128字节头/校验和通过 | 自动分辨率协商、屏幕一定正常 |
| EDID - | 未完成/未通过 | 区分断线和校验失败 |
| BRI、CON、MODE | 亮度、对比度与当前按键操作项 | 不表示音量；声音状态看A:、V: |
| SRC、FIT BILINEAR | 已确认图片宽高与保比例双线性缩放 | HDMI输出仍为640×480 |

LOAD错误优先显示；提交超时显示E时，内部仍可能保持忙保护缓冲区。

| 数码管码 | BMP路径状态 |
|---|---|
| 0 | 复位/SD未就绪 |
| 1 | 空闲，可能正在显示、无图或等控制 |
| 2 | 扫描或读图片头 |
| 3 | 等待帧写请求确认 |
| 4 | 读像素并送帧缓存 |

当前没有通过串口自动输出完整调试日志；`O_video_locked`没有接到诊断口，FIFO边界诊断也未接顶层可观测端，不能期待屏幕给出所有内部故障原因。

## 12. 遇到问题按层排查

| 现象 | 先检查 | 接下来怎么做 |
|---|---|---|
| 下载工具找不到器件 | 供电、驱动、下载线、启动模式 | 核对板卡下载接口；先不改BMP代码 |
| 拨码无反应 | 当前是否SW版bit、SW引脚和极性 | 开第1路再试第2路；模式需换图后观察 |
| HDMI无信号 | 显示器输入源、HDMI_B、线、供电 | 接好后复位，再查PLL/复位/HDMI电气 |
| 有背景无图 | FAT32挂载、根目录BMP数量和格式 | 查本轮FAT32教程与数码管错误；再定位SDRAM |
| 状态2较久 | 是否不足4张图仍在扫描 | 记录持续时间，不把扫描时间当停滞 |
| LOAD E | SD传输/CRC错误或FIFO欠载/溢出 | 记录静止时是否出现；按显示修复说明排查，复位清粘性标志 |
| 上下颠倒 | BMP正高度与额外翻转 | 使用工具原始输出，不额外翻转 |
| 偏色/撕裂/随机坏点 | 镜像、像素装配、SDRAM/FIFO/换帧 | 留照片和触发条件；不是亮度设置能解释的全部问题 |
| 无声 | 默认静音、VOLUME=00、错误镜像或显示器无音频支持 | 使用WAV候选，菜单AUDIO MUTE切OFF；按音频手册排查 |

异常恢复的真实行为：

- 初始化单次约8秒超时，暂停约1秒再试；一直没卡会周期重复，不表示已成功识别。
- 扇区约0.671秒无进度会终止传输；扫描阶段会重初始化后重扫。
- 已有索引的加载失败保留旧帧和索引，重新初始化后可按key1重试；换内容不同的卡整机复位。
- 可变尺寸整图加载约15秒超时中止；提交确认另等约5秒，超时只报错和保护缓冲，不冒充成功。迟到真实ack仍能完成，永远没有ack需整机复位。
- 视频溢出排空且到场边界可清除，不代表加密核全部异常都能自动恢复。

最新余量见 [构建状态](BUILD_STATUS.md)；内部复位removal不是HDMI管脚hold，未达到整体+0.5ns。SDRAM返回/刷新契约、PHY位置/布线警告及外部IO约束仍需继续验证，见 [待办](BOARD_PENDING.md)。
